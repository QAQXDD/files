# 示例剧本与改编笔记

> 说明：用户口述的原始剧本没有以文件形式保存在工程里，下面是根据成片工程（timeline.py 节拍表、场景代码）整理的**剧情梗概 + 改编笔记**，不是用户原文。做新一集时，节拍一律以用户当次给的原文为准。

## 1.《必吃榜》（Must-Eat List）— 盲目跟风 / 网红税

- 成片：`examples/bichibang.html`（38.6 s，9:16，可离线播放，右上角「导出 MP4」）
- 用户授权：**允许自由改编**（所以加了递进和插入镜头）。
- 讽刺对象：排长队、花大钱去“网红必打卡”店，买到的“招牌”是一记巴掌，挨完还发朋友圈好评，然后再去排队。

### 剧情梗概（按节拍）
| 时间 (s) | 节拍 |
|---|---|
| 0 – 3.3 | **钩子**：没有片名卡，直接是长队队尾，闪光灯狂闪、人群推挤，主角（渔夫帽、眼镜、紫卫衣+荧光绿马甲）举着手机挤在最后。 |
| 3.3 – 6.2 | 甩镜（whip-truck，横向拖影）一路沿队伍冲到最前面：霓虹拱门「全网必打卡」、牌匾《必吃榜》、TOP1 奖牌。 |
| 6.9 – 8.9 | 揭示：柜台空空，只有一台转个不停的“巴掌机”（转臂上一只大手），价签「招牌·巴掌 ¥888」。 |
| 8.9 – 10.7 | 主角鞠躬、掏出一沓钱，递进投币口，“叮”的收银声。 |
| 10.7 – 12.35 | 机器加速 → 停住 → **蓄力**（手臂先往后抡）→ 主角闭眼噘嘴把脸凑过去。 |
| 12.35 | **巴掌**：红色纸屑“血”、牙齿飞出，前排两个粉丝举手机狂拍。 |
| 12.35 – 16.0 | 主角在空中旋转飞出，最高点掏出手机**自拍**；插入镜头：手机屏幕上肿脸比耶的自拍。 |
| 16.0 – 18.35 | 落地扬尘 → 竖大拇指，头顶弹出「👍 绝绝子」徽章 → 抹一下嘴 → 转身。 |
| 18.35 – 26.6 | 往队尾走回去，头顶不断有别的顾客被扇飞（间隔越来越短：1.7 s → 0.45 s）。 |
| 26.6 – 31.4 | 大远景：柜台像喷泉一样把顾客一个接一个扇上天（每 0.36 s 一个）。 |
| 31.4 – 38.6 | 主角回到队尾，贴着创可贴、徽章“啪”地消失，再次举起手机推挤——镜头回到开场机位，**无缝循环**。 |

### 改编笔记（为什么这样拍）
- **空间装置**：一条笔直的夜街长队，镜头沿队伍横移，就能把“队尾 → 柜台 → 回到队尾”串成一个闭环。
- **递进**：飞过头顶的顾客间隔逐渐缩短，最后远景喷泉，把“不止他一个人傻”放大成社会现象。
- **道具字只留剧情必需**：「全网必打卡」「必吃榜」「招牌·巴掌 ¥888」「绝绝子」，没有任何字幕。
- **结尾循环**：用户反馈循环结尾很受欢迎；完播率考虑，开场 2 秒就是动态人群，不放片名卡。
- 声音：公有领域人群录音（Wikimedia Commons）+ numpy 合成（快门、巴掌、收银、机器呜呜声、120 bpm 网红 BGM）。BGM 在巴掌那一帧**硬切**，徽章弹出时才回来。

## 2.《对方正在输入中…》— 聊天框里的卑微等待

- 61.5 s，用户原剧本，**不加戏不删拍**（工程未附带成片）。
- 讽刺对象：发完消息就开始为“对方正在输入中…”疯狂准备，对方其实在开派对，最后只回了一个「哦」。

### 剧情梗概（按节拍）
| 时间 (s) | 节拍 |
|---|---|
| 0 – 5 | 圆形纸底座被一部**竖立的巨型纸手机**一分为二：前半边是主角整洁的小房间，后半边（手机淡紫色背面后）是女神的派对客厅。 |
| 5 – 13 | 主角把心掏出来，凿成一颗宝石（凿击声越来越快，0.6 s → 0.17 s），走过去推进手机的发送口。 |
| 15 – 23 | 屏幕出现“…”（正在输入），主角狂喜：换上丝绒西装、喷香水、**拉丝带弹出**立体书式的烛光晚餐（道具不凭空出现），摆好姿势。 |
| 25 – 37 | 延时：台灯亮起、蜡烛燃尽，“…”一直在跳。 |
| 37 – 51 | 镜头绕到手机背面：女神在派对上，手机掉在沙发垫里被屁股误触——“…”其实是这么来的；沙发每落一次座，前面就跳一下点点（落座节奏逐渐加快）。香槟塞子飞出。 |
| 51.8 – 55 | 回到正面：屏幕弹出一个「哦」气泡，「哦」变成一块小石子砸中主角，他摇晃、倒地（咚），石子落在两只 X 眼睛之间；悲伤长号。 |
| 55 – 61.5 | 俯拍定格 → 淡出。 |

### 改编笔记
- **空间装置**：手机本身就是墙——前后两个房间同时存在，镜头一绕就完成“真相揭示”。
- **反打镜头**：从屏幕那一侧拍主角时，加了一面“第四面墙”（女神的心形相框）给脸做背景。
- **一条声音线**：“正在输入”的气泡音贯穿全片，派对段与沙发落座同步，「哦」出现时全部停住。
- **结尾**：物体落点要准（石子正落在两眼之间），接悲伤长号。

## 3. 标杆：《甩锅乒乓球》（Blame Pong，约 60 s）
剖面金字塔办公楼：顶层老板把一颗“雷”打下来，经理用球拍扣杀，员工用文件夹互相传，最底层的实习生接住后爆炸，老板再扣一口锅在他头上（背锅）。成功点：层级就是楼层；一个物体从头跟到尾；双关变成物理动作；乒乓 40 拍间隔 0.95 → 0.21 s，越打越冒汗；引线滋滋声贯穿全片，在包袱处与背景乐一起断掉。
